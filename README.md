# بَيّنة AI | Bayyinah Engine 📜⚖️
### محرك التحقق المعرفي وتتبع الأدلة الشرعية لمكافحة الهلوسة ونفي الروايات غير الثابتة
> **المسار الرابع: أدوات المعرفة والتحقق** — تحدي الذكاء الاصطناعي في خدمة المحتوى الإسلامي 2026 (مؤسسة باذل).

---

## 📌 نبذة عن المشروع
**«بَيّنة AI»** منظومة استدلال مقيدة بالاسترجاع (**Grounded RAG**) مصممة خصيصاً لخدمة المحتوى الإسلامي، تهدف إلى **محاصرة وتصفير الهلوسة التوليدية (Zero Hallucination)** للنماذج اللغوية الكبيرة (LLMs) عند التعامل مع نصوص الحديث النبوي الشريف.

يعتمد النظام على الجمع بين **البحث المعجمي الدقيق والبحث الدلالي بالمتجهات (Hybrid Search)** مع تفعيل **بروتوكول الامتناع والرفض الذكي (Smart Abstention)**؛ بحيث لا يولد النظام أي نص أو يسند مقولة إلا إذا ثبت أصلها بقرائن قاطعة في الأمهات والكتب المعتمدة (صحيح البخاري، صحيح مسلم، الأربعين النووية).

---

## ✨ المميزات الرئيسية
* **التقييد الصارم بالأصول (Grounded RAG):** إلغاء التوليد الحر تماماً وحصر المخرجات في متون السنة المطهرة المعتمدة.
* **محرك بحث هجين (Hybrid Search with RRF):** دمج فهارس `pgvector` للمتجهات الدلالية مع البحث النصي الدقيق لحفظ الألفاظ النبوية.
* **بروتوكول الرفض الذكي (Smart Abstention):** امتناع فوري ومعلل عن النسبة أو التوليد عند فحص نصوص موضوعة أو لا أصل لها.
* **نظام مستويات القرار الثلاثية (3-Tier Decision Badges):**
  * 🟢 **المستوى الأول (ثقة ≥ 85%):** معتمد وصالح للنشر الفوري مع بطاقة الإسناد ورقم الحديث والباب وتخريج المحدثين.
  * 🟠 **المستوى الثاني (ثقة 60% - 84%):** محتوى مقارب يتطلب مراجعة وتثبت بشري (Human-in-the-Loop) لوجود تباين لفظي.
  * 🔴 **المستوى الثالث (ثقة < 60%):** غير ثابت بالأصول المعتمدة مع بيان سبب الامتناع.
* **قسم التحقق الذاتي (Self-Verification):** عرض النص المُدخل مقابلاً للمتن المعتمد جنباً إلى جنب (Side-by-Side) للفحص البصري الفوري.
* **تصدير بطاقات الإسناد الرقمية (Evidence Cards):** توليد وثائق تحقق موثقة بصيغ (HTML / TXT) تدعم مصداقية المحتوى الرقمي.

## 🚀 التشغيل السريع (Quick Start)

### المتطلبات الأساسية
* Docker & Docker Compose
* Python 3.10+ (في حال التشغيل المحلي المباشر)

### 1. استنساخ المستودع
```bash
git clone https://github.com/<username>/Al-Bayyinah-Engine.git
cd Al-Bayyinah-Engine
```

### 2. ضبط المتغيرات البيئية
أنشئ ملف `.env` في المجلد الرئيسي:
```env
BACKEND_URL=http://localhost:8080
GEMINI_API_KEY=your_gemini_api_key_here
POSTGRES_DB=bayyinah_db
POSTGRES_USER=postgres
POSTGRES_PASSWORD=postgres
POSTGRES_HOST=localhost
POSTGRES_PORT=5432
```

### 3. التشغيل عبر Docker Compose
```bash
docker compose up -d --build
```
* **واجهة المستخدم (Streamlit):** `http://localhost:8504`
* **توثيق الواجهة البرمجية (FastAPI Swagger Docs):** `http://localhost:8080/docs`
