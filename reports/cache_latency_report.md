## 2. ⚡ تحليل مقارنة أزمنة الاستجابة (Latency Breakdown)

```
[Cache Miss (Embedding + DB HNSW)]  ████████████████████████ 1017.30 ms
[Cache Hit (In-Memory Lookup)]      █ 17.29 ms  (58.85x Speedup 🚀)
```

1. **حالة غياب الكاش (Cache Miss):**
   * تتطلب المعالجة الكاملة: تنظيف النص -> توليد المتجه الشعاعي عبر Gemini (`text-embedding-004`) -> تنفيذ استعلام البحث الهجين (Full-Text Search + HNSW Vector Search) عبر `pgvector` -> تطبيق خوارزمية RRF وفحص عتبات الرفض الذكي.
   * زمن المعالجة يتراوح عادة بين **407 ms** إلى **1138 ms** (مع قفزة إلى **3697 ms** في الاستعلام الأول بسبب المصافحة الباردة Cold Start).
2. **حالة وجود الكاش (Cache Hit):**
   * تجاوز خط الأنابيب بالكامل والاعتماد على قفل آمن للخيوط (`threading.Lock`) فوق بنية `TTLCache`.
   * انخفض زمن المعالجة إلى ما بين **7.94 ms** و **33.28 ms** (بمتوسط عام قدره **17.29 ms**)، مما يحقق اشتراط الخدمة السريعة ($< 50\text{ ms}$).

## 4. 🛠️ التفاصيل المعمارية لطبقة التخزين المؤقت (Architecture Details)

### أ. تطبيع المفاتيح (Key Normalization Pipeline)
تقوم دالة `normalize_arabic_cache_key(text)` بتوحيد النصوص عبر المراحل التالية:
1. **Unicode NFKC Normalization:** توحيد ترميز المحارف المتوافقة.
2. **إزالة التشكيل (Tashkeel Stripping):** إزالة كافة الحركات والتنوين والشدة وعلامات الضبط القرآني (`U+0617`-`U+061A`, `U+064B`-`U+065F`, `U+0670`, `U+06D6`-`U+06ED`).
3. **إزالة الكشيدة (Tatweel Removal):** حذف حرف المد والتطويل (`\u0640`).
4. **توحيد الألفات والياءات:** تحويل `[إأآٱا] -> ا`، وتحويل `[ىي] -> ي`.
5. **توحيد التاء المربوطة والهاء:** تحويل `ة -> ه`.
6. **تجريد الرموز وعلامات الترقيم:** حذف الأقواس، علامات التنصيص العربية والإنجليزية، الفواصل، النقط، والنواقص.
7. **ضغط المسافات:** تحويل المسافات المتعددة إلى مسافة واحدة وإزالة المسافات الطرفية.

### ب. إدارة الذاكرة وتعدد المسارات (Concurrency & Lifecycle)
* **بنية الكاش:** مبنية على `cachetools.TTLCache` مع حد أقصى للحجم `maxsize=10000` وعمر زمني افتراضي `ttl=3600` ثانية (ساعة واحدة)، مع إمكانية الضبط عبر متغيرات البيئة `CACHE_MAXSIZE` و `CACHE_TTL`.
* **أمان التزامن (Thread Safety):** استخدام `threading.Lock` لضمان القراءة والكتابة الآمنة والمتزامنة داخل خوادم ASGI المتعددة (Uvicorn Workers).
* **الحفاظ على النقاء:** دعم استجابات التحقق الإيجابي (`verified`) والرفض الذكي (`refused`) لضمان عدم تكرار فحص المقولات الدارجة مسبقة الرفض.

### ج. واجهات المراقبة والتحكم (Observability Endpoints)
تمت إضافة نقاط نهاية خاصة للمراقبة والتحكم:
* `GET /api/v1/cache/stats`: يُرجع إحصائيات مباشرة تشمل:
  ```json
  {
    "status": "ok",
    "cache": {
      "size": 11,
      "maxsize": 10000,
      "ttl_seconds": 3600,
      "hits": 17,
      "misses": 11,
      "total_lookups": 28,
      "hit_ratio_percent": 60.71
    }
  }
  ```
* `POST /api/v1/cache/clear`: إفراغ الكاش وإعادة تصفير العدادات فورياً عند الحاجة.
* **الشفافية في الاستجابة:** إضافة حقل `"cached": true/false` في حمولة الرد `/api/v1/verify` لدعم التتبع الهندسي دون التأثير على الهيكل الأساسي.
